Always explain the issue and proposed solution in text first, then wait before making edits.

**Why:** User prefers to understand what's going wrong and agree on the fix before seeing a tool call.

**How to apply:** For any bug fix or code change, write a plain-text explanation of (1) the root cause and (2) the proposed fix, then make the edit — never lead with an Edit/Write tool call.
